# Integroitu korjaus 2026-11-24

Palautushaara ennen muutoksia:

## Tarkistetut rajapinnat

- Ohjelman valinta:
  ProgramManager -> StationController.set_program -> ForTestService ->
  ForTestManager (op 5) -> ForTestResultController ->
  StationController.handle_program_write_ack.
  Vasta hyväksytty kuittaus sallii STARTin.
- START:
  StationController -> TestValveController -> HardwareService ->
  ModbusManager/Opta (18092/18093) -> writeAcknowledged ->
  TestValveController.stateConfirmed -> ForTestManager (op 1) ->
  ForTestResultController.handle_start_ack. Kuittaamaton sulku estää STARTin.
- STOP:
  Peruuttaa odottavan STARTin, automaattisen jigin viiveet ja automaattisen
  restartin; abortoi ForTestin ja avaa NC VXA:n 10 sekunnin purkuajaksi
  (kuitattu Modbus-kirjoitus käynnistää ajastimen).
- Jigi:
  StationController -> HardwareService.request_jig_start ->
  yhden säikeen Opta-jigityöjono -> vahvistettu RUNNING ->
  request_jig_state -> DONE/ERROR. Asemavaraus estää ristikkäiset
  jigiohjaukset ja uuden ForTest-paineistuksen jigin liikkuessa.
- Opta:
  Yhteyden sarjaportti, lukeminen, kirjoitus ja reconnect ovat saman
  RLockin piirissä. Hätäseisluku käynnistää reconnectin taustasäikeessä.
- Testitulokset:
  StationResultHandler -> ResultStorageService ->
  data/test_results.db. Tallennusvirhe kirjataan tiedostoon
  data/test_results.db.pending.json, josta tulosta yritetään uudelleen.
  Duplikaatti tunnistetaan asemasta, aikaleimasta, ohjelmasta, tuloksesta
  ja raakarekistereistä.
- Sammutus:
  Opta SHUTDOWN_REQUEST 17999 -> 2 s viive -> asynkroninen
  sudo -n shutdown -h now. Komentovirhe raportoidaan käyttöliittymään.

## Muutosten rajat

**Fyysistä testausta ei korvaa mikään GitHubissa ajettava testi.**

- Venttiilin Modbus-kuittaus vahvistaa rekisterikirjoituksen, ei fyysistä
  venttiilin asentoa eikä todellista paineettomuutta.
- Jigien sylinterien asentoja ei voi vahvistaa ilman asentotunnistimia.
  Opta tarkistaa nyt D1608E-lisäosan olemassaolon; uusi vikakoodi on 6.
- Muutettu Aduino_opta_plc -koodi vaatii **erillisen Opta-firmware-
  latauksen**. Raspin Päivitä painetesteri -painike ei päivitä Optaa.
- sudoers-oikeudet, systemd ExecStart sekä automaattisammutuksen
  sähköinen toiminta on varmistettava fyysiseltä koneelta.
- Hätäseis ja paineenpurku on tarkistettava koneen todellisesta
  turvapiiristä. Ohjelmallinen STOP ei korvaa turvatoimintoja.

## Käyttöönoton testi

1. Varmista ennen testejä, ettei jigeissä ole painetta ja että
   fyysinen hätäseis toimii omana turvapiirinään.
2. Päivitä Raspberry kosketusnäytön Päivitä painetesteri -toiminnolla.
3. Varmista ForTest 1 ja 2:n sekä Optan tilat ja ohjelmanvaihdon kuittaukset.
4. Testaa START/STOP molemmille asemille; testaa STOP myös heti STARTin
   painamisen jälkeen.
5. Testaa OK/NOK-polut sekä yhteisen jigin valvonta soveltuvilla
   turvallisilla testikappaleilla.
6. Varmista ForTest- ja Opta-yhteyskatkon jälkeinen palautuminen
   hallitussa huoltotestissä.
7. Varmista SQLiteen tallentuneet tulokset ja varajonon tyhjeneminen.
8. Varmista automaattisammutus ja 10 s Opta-sammutusrele luotettavassa
   huoltotestissä.
